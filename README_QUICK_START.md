# ADHDo quick start

The current application is [ADHDo 2](adhdo2/README.md). Follow that guide for
installation, configuration and the source test command.

`./start.sh` and the older web-server instructions refer to the legacy
application, whose CI and compilation defects are tracked in
[#119](https://github.com/adrianwedd/ADHDo/issues/119). They are not a verified
zero-configuration route to ADHDo 2.

The [previous quick start](docs/archive/QUICK_START-legacy.md) is retained as history.
